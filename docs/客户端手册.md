# Desk-Emoji MCP 客户端手册

本文档用于指导用户通过 Desk-Emoji MCP 客户端连接和控制 Desk-Emoji 设备。客户端支持局域网发现、多设备连接、快捷控制、工具调用、日志查看和帮助查看。

## 1. 启动客户端

### 1.1 macOS / Linux

在客户端目录执行：

```bash
./start.sh
```

### 1.2 Windows

在客户端目录双击或执行：

```bat
start.bat
```

启动后进入图形界面，窗口标题显示当前客户端版本，例如 `Desk-Emoji MCP 客户端 v4.3.1`。

## 2. 界面导航

左侧导航栏包含 4 个页面：

- `控制`：搜索、选择、连接设备，并使用常用快捷控制。
- `工具`：读取设备 MCP 工具列表，查看工具说明并手动调用工具。
- `日志`：查看连接、搜索、发送、接收和错误日志。
- `帮助`：查看内置帮助文档。

左下角主题菜单支持 `System`、`Light`、`Dark` 三种外观模式。

## 3. 控制页

`控制` 页分为左侧设备连接区和右侧快捷控制区。

### 3.1 搜索设备

在 `局域网搜索` 区域填写搜索参数：

- `网段`：默认根据本机网络自动生成，例如 `192.168.1.0/24`。
- `端口`：默认 `8765`。多个端口可用英文逗号或分号分隔。
- `路径`：默认 `/mcp`。多个路径可用英文逗号或分号分隔；未以 `/` 开头时会自动补齐。
- `超时秒`：默认 `1.2`，用于控制单次探测等待时间。

点击 `搜索` 后，状态栏显示 `搜索中...`。搜索完成后，候选设备会显示在下方列表中，状态栏显示搜索到的设备数量。

客户端启动后也会自动监听 UDP 广播。设备主动广播时，会自动加入候选列表，无需手动点击搜索。

注意：搜索网段最多支持 1024 个主机地址。范围过大时，客户端会提示缩小网段。

### 3.2 选择和连接设备

搜索或自动发现到设备后，候选列表中会显示设备 WebSocket 地址，例如：

```text
ws://192.168.1.20:8765/mcp
```

操作步骤：

1. 勾选需要控制的设备。
2. 如需连接全部候选设备，勾选 `全选`。
3. 点击 `连接`。
4. 连接成功后，状态栏显示 `已连接: N 个 MCP 设备`。

客户端连接设备后会自动发送初始化请求。右侧快捷控制和工具页调用会广播到所有已连接设备。

点击 `断开` 可断开当前全部连接，状态恢复为 `未连接`。

### 3.3 声音控制

`声音` 区域提供以下操作：

- 拖动 `音量` 滑块后点击 `设置音量`，设置设备音量，范围 0-100。
- 勾选或取消 `静音`，立即切换静音状态。
- 在提示音下拉框选择音效后点击 `播放提示音`。
- 点击 `开始聆听`，让设备进入语音聆听状态。
- 点击 `停止聆听`，结束语音聆听状态。

### 3.4 头部控制

`头部` 区域用于控制设备头部动作：

- `方向`：可选 `left`、`right`、`up`、`down`。
- `偏移`：输入转向偏移量。
- `居中`：头部回到中心位置。
- `转向`：按当前方向和偏移量转动。
- `点头`：按 `循环/延迟/保持` 中的循环次数执行点头动作。
- `摇头`：按循环次数执行摇头动作。
- `左滚` / `右滚`：执行对应方向的滚动动作。

### 3.5 表情控制

`表情` 区域用于播放 GIF 和显示眼睛表情：

- `GIF`：输入 GIF 名称，例如默认值 `rocket`。
- `播放 GIF`：播放指定 GIF。
- `循环/延迟/保持`：依次填写循环次数、帧延迟毫秒、保持秒数。
- `随机 GIF`：按当前循环、延迟、保持参数播放随机 GIF。
- `眼睛`：可选 `blink`、`happy`、`sad`、`angry`、`surprised`。
- `显示`：显示当前选择的眼睛表情。

### 3.6 模式控制

`模式` 区域提供时钟、设置菜单和字符显示操作：

- `显示时钟`：短暂显示时钟。
- `开启时钟模式`：进入时钟模式。
- `退出时钟模式`：退出时钟模式，并恢复当前选择的眼睛表情。
- `打开设置菜单`：进入设备设置菜单。
- `关闭设置菜单`：退出设备设置菜单。
- `回车显示字符`：输入不超过 10 个字符，按回车后在设备屏幕显示。
- `关闭显示字符`：清除屏幕字符，并恢复 `blink` 眼睛表情。

### 3.7 OTA 设置

`OTA` 区域用于设置设备固件升级地址：

- 在 `自定义地址` 输入 OTA URL。
- 点击 `设置 OTA 地址` 或在输入框按回车提交。
- 点击 `恢复默认 OTA` 恢复设备默认 OTA 地址。

OTA URL 必须满足以下条件：

- 使用 `https` 协议。
- 包含有效主机名。
- 长度为 10-512 个字符。
- 不能包含空白字符。
- 如包含端口号，端口必须在 1-65535 之间。

## 4. 工具页

`工具` 页用于查看和调用设备 MCP 工具。

### 4.1 列出工具

操作步骤：

1. 确保已在 `控制` 页连接至少一台设备。
2. 进入 `工具` 页。
3. 点击 `列出工具`。
4. 左侧 `工具列表` 会显示设备返回的工具名称。

如果连接了多台设备，同名工具会合并显示，并在名称后标注来源设备数量，例如 `(2 servers)`。

勾选 `用户工具` 后再点击 `列出工具`，客户端会请求并显示设备标记为用户可见的工具。

### 4.2 查看工具说明

在左侧工具列表点击任一工具：

- 右侧 `工具说明` 显示该工具的完整 JSON 信息，包括名称、描述、参数 schema 和来源设备。
- 右侧 `调用参数` 自动生成可编辑的 JSON 参数模板。

### 4.3 调用工具

操作步骤：

1. 在左侧选择一个工具。
2. 在 `调用参数` 中确认或修改 JSON 参数。
3. 点击 `调用工具`。

调用会广播到所有已连接设备。如果参数不是合法 JSON object，客户端会提示 `Arguments JSON 格式错误`。

点击 `重置参数` 可根据工具 schema 重新生成默认参数模板。

## 5. 日志页

`日志` 页用于查看运行过程中的详细记录，包括：

- UDP 自动发现结果。
- 手动搜索开始和完成信息。
- WebSocket 连接、关闭和错误信息。
- MCP 请求发送内容。
- MCP 响应接收内容。
- 广播失败和异常提示。

点击 `清空` 可清除当前界面日志。

客户端同时会把日志写入本地 `logs` 目录，文件名按日期生成，例如：

```text
logs/2026-08-01.log
```

## 6. 帮助页

`帮助` 页显示项目内置文档。文本框上方的标签页会列出 `docs` 目录下的 Markdown 文档，标签名使用文件名；切换标签后会重新读取并渲染对应文档。

页面底部的 `杭州易问科技版权所有` 可点击打开官网链接。

## 7. 常见问题处理

### 7.1 搜索不到设备

请检查：

- 电脑和 Desk-Emoji 设备是否在同一局域网。
- `网段` 是否与当前网络匹配。
- 设备 MCP 服务端口是否为 `8765`。
- 设备 MCP 路径是否为 `/mcp`。
- 防火墙是否阻止 UDP 广播或 WebSocket 连接。

### 7.2 点击控制按钮提示发送失败

通常表示当前没有可用连接。请先在 `控制` 页搜索设备、勾选设备并点击 `连接`。

### 7.3 工具列表为空

请检查：

- 是否已成功连接设备。
- 是否点击了 `列出工具`。
- 勾选 `用户工具` 时，设备是否支持用户工具返回。
- 可在 `日志` 页查看 `tools/list` 请求和响应内容。

### 7.4 OTA 地址无法提交

请确认 OTA 地址使用 `https://` 开头，且地址中没有空格。地址格式不正确时，客户端会弹出具体错误原因。

### 7.5 多设备动作不同步

客户端会并行向已连接设备广播命令，但实际动作时间还受网络延迟、设备负载和设备当前状态影响。需要同步控制时，建议提前连接所有设备，并使用相同参数触发同一动作。
